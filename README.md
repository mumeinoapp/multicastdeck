# MultiCastDeck（Twitch/YouTube/Kick マルチストリーム & Drops 統合ツール）

Twitch・YouTube・Kickを複数同時に見たい、チャットもまとめて追いたい、Dropsの取りこぼしをなくしたい——そんな悩みを解決するWindows向けデスクトップアプリです。基本機能は無料で使えます。

最新版のダウンロードは [GitHub Releases](https://github.com/mumeinoapp/multicastdeck/releases) から。

## セットアップ（開発者向け）

```bash
cd MultiCastDeck
npm install
npm start
```

初回起動後、右上の「⚙ 設定」から `parent` ドメインやレイアウト列数、スタンプ機能用のTwitch Helix Client ID/Secretを設定してください。

## 実装済み機能

- **複数チャンネルの同時視聴**：Twitch・YouTube・Kickのチャンネルをタイルとして好きなだけ並べて同時視聴。タイルはドラッグで自由に移動・リサイズでき、「自動整列」でグリッドにも戻せる
- **チャット統合**：各配信のチャットを埋め込み表示。タイル配置やレイアウトは共有URLとして書き出し・取り込みができ、お気に入りの配置を他の人と共有できる
- **Dropsインベントリ表示**：Twitch/Kickの公式Dropsページをアプリ内でそのまま確認できる（「確認操作をした時だけ」読み取るオンデマンド設計。常時ポーリングはしない）
- **スタンプ（エモート）機能**：Twitchのチャンネル固有・グローバルエモートを一覧表示し、クリックでチャット欄へ挿入・お気に入り登録も可能（Twitch Helix APIのClient Credentials方式を利用）
- 配信/チャット読み込み失敗時のエラー通知、チャンネル追加/削除・並び順・設定のローカル永続化（`electron-store`）

配信サイトごとの対応状況には差があります（YouTube・Kickは一部機能が非公式の方法で実現されているため、公式側の仕様変更で動かなくなる可能性があります）。詳しい対応範囲・既知の制約はアプリ内メニューバーの「使い方 / 注記」から確認できます。

## Pro会員向け機能（有料）

以下の機能はメニューバーの「会員登録」から加入できるPro会員向けです。

- **配信チェック**：フォロー中/登録中で現在配信中のチャンネルを統一フィードで表示（Kickも対応。YouTubeは配信チェック内でのチェック登録が必須）
- **チャット統合の「全タブ統合」モード**：開いている全タイルのチャットを1つにまとめて表示
- **ザッピング**：条件（ゲーム・言語など）を指定した配信のランダム自動切り替え（YouTube版はβ・非公式方式のため言語絞り込み非対応）
- **Drops自動追加/削除**：指定ゲームの配信中チャンネルを自動追加/削除（60秒間隔）

## 決済方法

- **クレジットカード**：Stripe Checkoutによる完全自動更新のサブスクリプション（毎月自動課金・失敗時リトライ・解約までStripeが処理）
- **銀行振込・PayPay**：1・6・12か月から選択する都度払い（まとめ払いほど割引）

購入導線はアプリ内の「会員登録」から。既定のブラウザでStripe Checkoutのページを開く方式で、アプリ内にカード情報の入力画面等は持たない。

## アップデート確認機能

メニューバーの「バージョン」から、現在のバージョン表示・確認・（見つかった場合の）ダウンロード・再起動して適用ができる（ウィンドウやパネルは出さず、ネイティブのドロップダウンメニューだけで完結）。

- 起動時にも自動で静かにチェックする（ダイアログは出さない）。結果は「バージョン」メニューを開けば分かる
- 新しいバージョンが見つかっても自動ではダウンロードしない。メニュー内「ダウンロードする」を選んだ時だけ開始する
- ダウンロード完了後は「今すぐ更新して再起動(アプリ)」を選ぶまで適用されない（PC自体の再起動ではなくアプリの再起動であることを明記）
- 手動確認が失敗した場合のみ、ネイティブダイアログでエラーを知らせる

## フィードバック機能

メニューバーの「フィードバック」から、件名・本文を開発者へ直接送信できる。不具合報告・要望はここから受け付けている。

## リリース手順（アップデート配布）

新しいバージョンを配布する際は、以下の手順で行う。

1. `package.json` の `version` を更新する（例: `0.2.4`）
2. `CHANGELOG.md` の `[Unreleased]` に書いていた変更点を、新しいバージョン番号の見出しの下に移動する（日付も記載）
3. GitHubのPersonal Access Token（`repo`権限）を発行し、環境変数 `GH_TOKEN` に設定する
4. `npm run release` を実行する（`electron-builder --win --publish always`）。ビルドしたインストーラーが GitHub Releases（`https://github.com/mumeinoapp/multicastdeck/releases`）に自動でアップロードされ、`latest.yml` も生成される（これをアプリ内の「バージョン」メニューが参照する）
5. GitHub Releases画面で、そのリリースの説明欄に `CHANGELOG.md` の該当バージョンの内容を貼り付けて公開する（Draftのまま作られるので、内容を確認してから「Publish release」を押す）
6. 配布が確認できたら、はてなブログ（`https://mumeinoapp.hatenablog.com/`）に更新内容の記事を投稿する

## 既知の制約（要フォロー）

- `parent` パラメータの初期値は `localhost`。実配布時は配布ドメインに応じて設定画面で変更が必要
- YouTube・KickのDrops進捗・配信中判定・登録チャンネル取得などは、公式APIが存在しない・有料枠のみのため非公式のページ読み取り方式で実現している。各サイトのDOM/ページ構造変更で動作しなくなる可能性があるため、実機での定期的な動作確認が必要（非公式機能である旨はアプリ内「使い方 / 注記」にも明記済み）
- スタンプ機能はTwitch Developer Consoleでの無料アプリ登録（Client ID/Secret取得）がユーザー側で必要
- お気に入りエモートのコピーはコード名（`:name:`）のクリップボードコピーまでで、実際の投稿は引き続き各配信サイト公式のチャット欄で行う設計

## 既知のリスク

- Drops進捗表示・配信中判定・広告自動ミュート等は非公式機能。各配信サイト側の仕様変更で機能停止する可能性がある
- 個人アカウントBANの明確な事例は確認されていないが、可能性はゼロではない
